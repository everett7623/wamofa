WhatsApp Web 工作台

翻译和备注留在这台浏览器里

WAMofa 给 WhatsApp Web 加上 AI 翻译、客户档案、快捷回复和语音转写。 没有云端账号，不群发，也不会替你按下发送。

自行加载扩展 查看源码

独立开源项目，与 WhatsApp 官方无关联。MIT 许可。

它做什么

来消息翻译

在气泡旁点一下翻译，或按联系人打开自动翻译。译文缓存在本机，大约保留 7 天。

智能译出

把输入框里的话译成对方语言，先预览再写回输入框。你自己按 Enter 发送。

客户档案

备注、标签、发出语言都存在本机。能解析到号码时，显示国家、时区和是否在工作时间。

快捷回复

预设话术，会话里用 Alt+Shift+R 插入输入框。

语音转写

把语音消息交给你自己配置的转写接口（例如 Whisper），结果可以再翻译。

快速开聊

输入完整国际号码（以 + 或 00 开头），跳转官方 web.whatsapp.com/send 链接，不写入通讯录。

明确不做

这些能力故意没有，也不会加。

  • 群发、定时发送、自动回复
  • 查号、导出群成员、备份或同步对话
  • 把号码或聊天内容上传到 WAMofa 自己的服务器（这个站点也不收集）
  • 修改 WhatsApp 的发送逻辑，或代替你点击发送

安装

目前需要从源码加载，尚未上架 Chrome 网上应用店。需要 Node.js 20+，Chrome 或 Firefox。

  1. 克隆仓库并构建：

    git clone https://github.com/everett7623/wamofa.git
    cd wamofa · npm install · npm run build

  2. Chrome 打开 chrome://extensions，打开开发者模式，加载 .output/chrome-mv3（不要选仓库根目录）。

  3. 打开扩展选项页，填入你自己的 AI 服务商与 API Key。支持 OpenAI、Claude、DeepSeek、智谱 GLM、通义千问、Gemini、Grok、Sub2API 以及自定义 OpenAI 兼容接口。

改代码后：重新加载扩展，再刷新 web.whatsapp.com。快捷键一律是 Alt+Shift 加字母：R 回复、I 档案、T 译出、H 隐藏译文。
