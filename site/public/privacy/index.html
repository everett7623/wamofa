Privacy

隐私政策

最近更新：2026 年 9 月 20 日。本页同时提供英文，供 Chrome 网上应用店审核使用。

WAMofa 是安装在你浏览器里的扩展，官方站点是 wamofa.com。 我们没有用户账号，也没有用于接收你聊天内容的云端服务。

这个网站收集什么

不收集。官网是静态页面，没有账号、没有 Cookie、没有分析脚本、没有表单回传。

扩展把数据放在哪里

备注、标签、快捷回复、AI 设置（含 API Key / Project Key）、会话级选项，以及翻译缓存，都写在本机 chrome.storage.local。换浏览器或清站点数据就会丢失，这是产品设计，不是缺陷。

  • 主配置键 wamofa：设置、模板、标签、会话元数据。
  • 翻译缓存键 wamofa_tx：约 7 天过期，最多约 500 条。
  • 会话身份优先用 phone:号码，解析不到号码时用 title:标题。 若你手动填写了号码，该号码会作为本地会话键和档案字段保存，不会上传到 WAMofa。
  • 页面脚本拿不到完整密钥，只能看到「是否已配置」；密钥只在扩展后台脚本里用于发请求。

什么会离开这台电脑

只有你主动使用翻译或语音转写时，相关文本或音频才会发往你自己填写的 AI 服务商 （例如 OpenAI、Anthropic、DeepSeek、智谱、通义、Gemini、xAI，或自定义 OpenAI 兼容地址）。 请求使用你自己的密钥。WAMofa 作者看不到这些请求。

「快速开聊」只会打开 WhatsApp 官方链接 https://web.whatsapp.com/send?phone=…，由 WhatsApp 处理。

权限为什么要这些

  • storage：读写上面的本地配置和缓存。
  • https://web.whatsapp.com/*：在 WhatsApp Web 页面注入翻译、档案和快捷回复界面。
  • https://*/* 以及本机地址：因为 Base URL 由你指定，扩展需要能访问你配置的任意 AI 接口。 扩展不会用这个权限去扫描其他网站。

我们不做什么

  • 不把聊天记录、通讯录或号码同步到 WAMofa 服务器（没有这样的服务器）。
  • 不提供云备份、数据导出到第三方、群发或自动回复。
  • 本站点与扩展均不嵌入广告或追踪像素。

如何删除数据

卸载扩展，或在浏览器中清除该扩展的本地存储。翻译缓存也会随 TTL 自动过期。 第三方 AI 服务商各自有自己的数据处理政策，需要到对应厂商处查看。

联系

问题与隐私相关请求请开 GitHub Issues。 源码：github.com/everett7623/wamofa。

English

Last updated: 20 September 2026.

WAMofa is a browser extension for WhatsApp Web. The project website is wamofa.com. There are no user accounts and no WAMofa backend that receives your chats.

This website is static. It does not set cookies, run analytics, or collect personal information.

Inside the extension, notes, tags, templates, AI credentials, per-chat settings, and translation cache live in chrome.storage.local on your device. Translation cache expires after about 7 days and is capped at about 500 entries. Chat records may be keyed locally by a phone number when one can be parsed, or by the chat title otherwise. A number you type in manually is stored only on this device.

API keys are readable only by the extension’s background script. The content script on WhatsApp Web receives a public state object without the raw keys.

Text or audio leaves your computer only when you translate or transcribe, and only to the AI provider URL you configured, using your own key. “Open chat” uses WhatsApp’s official web.whatsapp.com/send URL.

Host permission https://*/* exists so the extension can call whatever OpenAI-compatible endpoint you enter. It is not used to scrape other sites. Uninstall the extension or clear its local storage to delete data held by WAMofa. Third-party AI providers have their own policies.

Contact: GitHub Issues.
