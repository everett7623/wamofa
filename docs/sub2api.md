# Sub2API 配置

选项页选择 **Sub2API（自建网关）**。默认用 API Key（`Authorization: Bearer`）；也可改成 Project Key，并自定义 Header 名称与格式。

## 建议填写

| 项 | 说明 |
| --- | --- |
| Base URL | 网关根地址，或带 `/v1` 的地址均可 |
| API Key / Project Key | 按你的网关要求填写 |
| 文本模型 | 填写网关实际暴露的模型名；可用「读取模型列表」拉取 |

## 常见问题

**返回 HTML 而不是 JSON**  
多半是 Base URL 指到了管理后台页面，或鉴权失败被跳到登录页。改成正确的 API 地址并核对 Key。

**模型列表为空或 404**  
确认网关开放了 `v1/models`，且当前 Key 有权限。也可关掉列表，手动填模型名。

**翻译超时**  
检查网关分组、模型名是否写对，以及本机到网关是否可达。
